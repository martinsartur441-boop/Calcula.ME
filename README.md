# Calculadora Tributária

Aplicação web estática para simulação de ICMS, ISS, IBS e CBS.

## Como usar
Abra `index.html` em qualquer navegador moderno.

## Observação
A aplicação foi estruturada para permitir atualização das alíquotas por ano. Ela não é um motor fiscal completo: não contempla automaticamente todos os regimes, créditos, benefícios, regimes específicos, regras de local da operação, substituição tributária, Simples Nacional etc.

Fontes oficiais consultadas:
- Receita Federal — Reforma Tributária do Consumo
- Lei Complementar nº 214/2025, texto compilado com alterações da LC 227/2026
